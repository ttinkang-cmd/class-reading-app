# 📚 학급 윤독도서 관리 웹 애플리케이션 (MVP)

디벗(크롬북), 태블릿, 스마트폰 환경에서 학급 학생들이 매주 한 권씩 책을 순환하며 읽고 완독 체크 및 3줄 독서록을 나눌 수 있는 웹 서비스입니다.

---

## 🌟 핵심 기능 및 특징

1. **학생 수 맞춤 순환 로테이션 (Rotation Engine)**
   - 학생 수($N$명)만큼의 책이 구비되어 있고, 매주 번호 순서대로 연달아 다음 책으로 넘어갑니다.
   - 마지막 번호의 책을 읽은 학생은 다음 주에 1번 책으로 순환 이동합니다.
   - 메인 화면 매트릭스에서 이번 주 해당 학생이 읽어야 할 책이 **노란색 '이번주' 배지**로 선명하게 하이라이트됩니다.

2. **한눈에 보는 가로×세로 독서 현황판 (Matrix Grid)**
   - **가로축(상단)**: 도서 번호, 표지 이모지, 책 제목, 이번 주 배당 학생 표시
   - **세로축(좌측)**: 학생 번호 및 이름 (화면 스크롤 시에도 상단/좌측이 고정되는 **Sticky 헤더**)
   - **교차 셀**: 클릭 한 번으로 손쉽게 **완독 여부(초록색 체크 마크)**를 토글할 수 있습니다.

3. **책 표지 클릭 시 3줄 느낀 점(독서록) 모달**
   - 상단 책 표지를 누르면 그 책을 읽은 친구들의 3줄 소감 목록을 확인할 수 있습니다.
   - 학생들이 자신의 디벗에서 **[본인 이름 선택] + [3줄 느낀 점] + [비밀번호 4자리]**를 입력하여 등록합니다.
   - **타인 글 수정/삭제 방지**: 작성 시 설정한 4자리 PIN을 대조하므로 다른 학생이 임의로 글을 삭제하거나 수정할 수 없습니다.

4. **하이브리드 데이터베이스 (Supabase + LocalStorage)**
   - 별도의 서버 설치나 DB 설정 없이도 **즉시 브라우저에서 100% 동작**합니다 (로컬 저장 모드).
   - Supabase 무료 프로젝트의 URL과 Key를 설정하면 즉시 **실시간 동기화 모드(우리 반 30명 동시 사용)**로 자동 전환됩니다.

## 🚀 빠른 시작 방법 (지금 바로 확인하기)

1. 폴더 내의 **`index.html` 파일을 더블 클릭**하여 크롬(Chrome)이나 엣지(Edge) 브라우저에서 바로 엽니다.
2. 상단 주차 컨트롤러(`[이전 주]`, `[다음 주]`)를 눌러 도서가 규칙대로 학생들에게 순환 배정되는지 확인해 보세요.
3. 책 표지를 눌러 친구들의 느낀 점을 확인하거나 3줄 소감을 직접 등록해 보세요.
4. 그리드의 사각형을 클릭하여 완독 체크를 해보세요.

## ☁️ Supabase 무료 데이터베이스 연동 3단계 가이드

학급 30명이 각자의 디벗에서 실시간으로 함께 보려면 Supabase에 무료 프로젝트를 연결하세요.

### 1단계: Supabase 프로젝트 생성 (무료)
1. [supabase.com](https://supabase.com)에 접속하여 무료 회원가입을 합니다.
2. **`New project`** 버튼을 누르고 프로젝트 이름(예: `our-class-reading`)과 비밀번호를 입력 후 생성합니다.

### 2단계: 데이터베이스 테이블 생성 (1초 완성)
1. Supabase 왼쪽 메뉴에서 **`SQL Editor`** 아이콘을 클릭합니다.
2. 본 폴더에 있는 **`supabase_schema.sql`** 파일의 전체 내용을 복사하여 SQL 창에 붙여넣습니다.
3. 우측 하단의 **`Run`** 버튼을 누르면 학생 30명, 도서 30권, 체크 기록, 3줄 느낀 점 테이블이 즉시 자동 생성됩니다.

### 3단계: 웹 화면에서 키 연결
1. Supabase 왼쪽 메뉴의 **`Project Settings (톱니바퀴)` → `API`**로 이동합니다.
2. `Project URL`과 `anon public key`를 복사합니다.
3. 본 웹 화면 우측 상단의 **[⚙️ 설정]** 버튼을 누르고 URL과 Key를 붙여넣은 뒤 [설정 저장하기]를 누르면 끝입니다!
   - 상단 상태 표시가 **'실시간 동기화 (Supabase)'**로 바뀌며 실시간 협업이 시작됩니다.

## 🚀 Vercel 배포 방법 (1분 완성)

이 프로젝트는 별도의 빌드 과정이 필요 없는 초경량 웹 애플리케이션으로, Vercel에 드래그하거나 GitHub으로 연결하면 즉시 배포되어 무료 도메인(`https://your-app.vercel.app`)이 발급됩니다.

### 방법 1: GitHub을 통한 배포 (가장 추천)
1. 현재 `dev` 폴더의 코드들을 본인의 GitHub 저장소(Repository)에 커밋 및 푸시합니다.
2. [vercel.com](https://vercel.com)에 로그인 후 **`Add New...` → `Project`**를 누릅니다.
3. 방금 올린 GitHub 저장소를 선택하고 **`Deploy`** 버튼을 누릅니다. (설정을 건드릴 필요 없이 그대로 배포됩니다!)
4. 완료되면 발급된 주소(URL)로 접속하여 QR코드를 만드시면 됩니다.

### 방법 2: Vercel CLI로 바로 배포
터미널에서 `npx vercel` 명령어를 입력하고 화면의 질문에 엔터만 치면 로컬 폴더가 즉시 배포됩니다.

## 🔒 개인정보 및 보안 안내

- **학생 얼굴 및 성적**: 시스템 내에 일체 수집하거나 저장하지 않습니다.
- **학생 이름**: 학급 웹사이트 링크를 공유받은 반 학생과 선생님만 열람할 수 있습니다. 이름 외부 노출을 원치 않으시면 `supabase_schema.sql`에서 `1번 김*윤` 형태로 마스킹하여 운영하실 수 있습니다.
- **글 보호**: 각 학생이 글을 작성할 때 4자리 PIN을 설정하여 타인이 글을 임의로 훼손하지 못하도록 방어되어 있습니다.
